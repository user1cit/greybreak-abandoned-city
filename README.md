# Greybreak: Abandoned City

A browser-playable first-person survival RPG inspired by early 1990s raycasting shooters, set in an abandoned city.

Open `index.html` directly in a browser. The root page forwards to the playable game in `outputs/index.html`.

## Controls

- Move: `W` / `S` / `A` / `D`
- Turn: arrow keys or mouse after clicking the canvas
- Run: `Shift`
- Fire: `Space` or mouse click
- Interact: `E`
- Use food/water/aid: `1` / `2` / `3`
- Equip weapons: `4` / `5` / `6`
- Settings: gear button or `Esc`

Settings and remapped controls are stored in browser `localStorage`.
